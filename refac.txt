Является ли Python «удачным»?
Да, для большей части планов — это самый удачный выбор:

ИИ-интеграция — Python тут стандарт де-факто. Все основные SDK/библиотеки LLM-агентов (OpenAI, Anthropic, LangChain, автономные агенты) написаны под Python. Лучше языка просто нет.
Графики — Matplotlib, Plotly, pyqtgraph, KPIs. Всё зрелое.
Парсинг сайтов — requests/BeautifulSoup/lxml/scrapy — это родная стихия Python.
Финансовый анализ — pandas, numpy, для торговой статистики это именно то, что нужно.
Но есть нюансы, которые стоит признать:

Скорость — для тяжёлого анализа/бэктестинга Python медленный. Решается numpy/pandas (векторизованно) или выносом тяжёлого в C/Rust.
GUI на Qt — для связки «анализ + графики» Qt — разумно, но десктоп тут у тебя, скорее всего, временное решение.
По поводу «ИИ плохо работают с нетипизированными языками»
Тут популярное заблуждение. Качество работы ИИ определяется контекстом и структурой кода, а не языком. Python с типами через typing/dataclass — отлично справляются. Но вот что реально сейчас мешает ИИ и тебе в этом коде:

Смешаны PyQt5 и PySide2 одновременно (main.py:6-9) — конфликтующая пара, из-за этого неизбежны ошибки.
import * в начале (main.py:12-14) — убивает контекст и типизацию.
Данные — это голые списки строк self.data (список списков), индексы хардкодятся (row[4], row[1]) — легко оторвать. Хранится в XML руками.
Класс Deal объявлен без правильного __init__ (общие поля класса, не объекта) — баг.
