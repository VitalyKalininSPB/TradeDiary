# ============================================================================
# S&P 500 — backtesting через фьючерсы (доходность в долларах USD)
# ============================================================================
# Цель: оценить доходность стратегии MLRCI (STRONG BUY/SELL) на 500 000 ₽,
# НО через ФЬЮЧЕРСЫ на S&P 500 (индекс напрямую купить нельзя — только через
# производные). Здесь расчёт только в долларах (без рублёвой конвертации),
# с учётом "временного распада" фьючерса (roll / cost of carry / contango).
#
# Даты построения: 31.08.2026. Данные: FRED (макро + спот SP500), Yahoo Finance
# (непрерывный фронт-месяц E-mini S&P 500 futures, ES=F), MOEX (SP500F, курс).
# ============================================================================

# ----------------------------------------------------------------------------
# 1. ИНСТРУМЕНТЫ ДЛЯ ТОРГОВЛИ S&P 500 (что реально доступно)
# ----------------------------------------------------------------------------
# Проблема: сам индекс S&P 500 торговать нельзя, нужна производная.
#
# a) CME E-mini S&P 500 Futures (ES) — эталонный ликвидный фьючерс на S&P 500.
#    * Множитель контракта: $50 x индекс (1 пункт ES = $50).
#    * Торгуется почти 24/5 на CME, самый ликвидный индексный фьючерс в мире.
#    * Непрерывный ряд ES=F (Yahoo) = фронт-месяц, автоматически "роллится"
#      с контракта на контракт (март/июнь/сентябрь/декабрь).
#    * Для бэктеста в USD это лучший прокси: история с 2023, плотные свечи.
#
# b) SP500F — фьючерс на S&P 500 на MOEX (добавлен в конце 2026).
#    * Пункт ≈ 771 (т.е. ~индекс/10). Множитель/лот в marketdata есть.
#    * ВАЖНО: первые свечи только 04.08.2026, всего ~20 свечей на 31.08.2026.
#      => Для бэктеста "с 2024" СП500F НЕпригоден (истории просто нет).
#    * SP500F пригоден только для ПЕРСПЕКТИВНЫХ/будущих сделок с авг 2026.
#    * Данные: MOEX ISS
#      /iss/engines/futures/markets/forts/securities/SP500F/candles.json
#
# Вывод: исторический бэктест 2024-2026 делаем по ES=F (CME), а SP500F (MOEX)
# фиксируем как доступный ТОРГУЕМЫЙ инструмент на российском рынке с авг 2026.

# ----------------------------------------------------------------------------
# 2. СИГНАЛЫ MLRCI (источник: mlrci.py, compute_mlrci_full)
# ----------------------------------------------------------------------------
# STRONG BUY / STRONG SELL = confluence >=4 из 5 условий:
#   Real rate, NTFS, Net Liquidity (WALCL-TGA-RRP), BBB spread, VIX.
# С 2024 года сигналы:
#   BUY  2023-11-17  -> состояние "в рынке" на начало 2024 (BUY активен)
#   BUY  2024-02-20  -> подтверждение BUY (вход по первому сигналу в 2024)
#   SELL 2026-08-07  -> выход
#   SELL 2026-08-12  -> подтверждение SELL
#   SELL 2026-08-27  -> подтверждение SELL
#
# Стратегия простая: BUY => лонг по ES, SELL => закрытие (в кэш).
# Два варианта входа (оба считаем):
#   A) в рынке с начала 2024 (01.01.2024 / первый торг. день 02.01.2024)
#   B) вход по BUY 20.02.2024
# Выход в обоих: SELL 07.08.2026.

# ----------------------------------------------------------------------------
# 3. ЦЕНЫ ES=F (USD) НА КЛЮЧЕВЫЕ ДАТЫ
# ----------------------------------------------------------------------------
#    Дата        ES=F       SPX spot   ES/SPX (базис)
# 2024-01-02   4 820.00    4 769.83      1.0105
# 2024-02-20   5 019.75    5 005.57      1.0028
# 2026-08-07   7 734.75    7 709.96      1.0032
# 2026-08-28   7 742.50    7 730.99      1.0015
#
# Базис ES/SPX ~ 1.0015-1.0105 — фьючерс чуть дороже спота (cost of carry:
# безрисковая ставка минус дивдоходность). Это и есть источник "распада".

# ----------------------------------------------------------------------------
# 4. ДОХОДНОСТЬ (USD, БЕЗ КОНВЕРТАЦИИ В РУБЛИ)
# ----------------------------------------------------------------------------
# ES=F:
#   A) лонг с 02.01.2024 по SELL 07.08.2026:
#      (7 734.75 / 4 820.00 - 1) = +60.47%
#   B) вход по BUY 20.02.2024 (5 019.75) -> выход 07.08.2026 (7 734.75):
#      (7 734.75 / 5 019.75 - 1) = +54.08%
#   Бай-энд-холд ES=F 02.01.2024 -> 28.08.2026:
#      (7 742.50 / 4 820.00 - 1) = +60.63%
#
# СПОТ S&P 500 (SPX, для сравнения без ролла):
#   Бай-энд-холд SPX 02.01.2024 -> 28.08.2026:
#      (7 730.99 / 4 769.83 - 1) = +62.08%
#
# => Стратегия MLRCI на ES: +60.47% (вариант A) / +54.08% (вариант B).
#    Бай-энд-холд ES: +60.63%.  Бай-энд-холд спот SPX: +62.08%.

# ----------------------------------------------------------------------------
# 5. "ВРЕМЕННОЙ РАСПАД" / РОЛЛ ФЬЮЧЕРСА (cost of carry, contango)
# ----------------------------------------------------------------------------
# Фьючерс НЕ "распадается" как опцион: держатель лонга не теряет гамму/тету.
# Но есть roll & financing-компонент:
#   * Непрерывный ряд ES=F (Yahoo) роллится на следующий контракт при экспирации.
#   * Обычно кривая ES в контанго (дальние контракты дороже) -> при ролле
#     продаём старый (дешевле) и покупаем новый (дороже) => небольшой минус.
#   * За финансирование (безрисковая ставка) тоже "платим" через базис.
#
# Измерение: разница между полной доходностью ES=F и спотом SPX за тот же
# период = совокупный ролл/финансинг-дрэг:
#   (ES buy&hold) / (SPX buy&hold) - 1 =
#   (7 742.50 / 4 820.00) / (7 730.99 / 4 769.83) - 1 = -0.89%
#   за период 01.2024 - 08.2026 (~2.65 года) => ~ -0.34%/год.
#
# => Временной распад НЕЗНАЧИТЕЛЕН: ~0.9% за весь период (около -0.34%/год).
#    Это подтверждает: для лонговой стратегии на S&P 500 фьючерс ES почти
#    идентичен споту по доходности (спот чуть лучше из-за отсутствия ролла).

# ----------------------------------------------------------------------------
# 6. ЧТО ОЗНАЧАЕТ ЭТО ДЛЯ ИНВЕСТОРА
# ----------------------------------------------------------------------------
# * С 2024 по 2026 (2.65 года) лонг по ES с сигналами MLRCI дал бы
#   +60.47% в долларах (вариант A) — это ближе всего к бай-энд-холду (+60.63%),
#   потому что сигнал SELL пришёлся на 07.08.2026, когда индекс уже был на
#   максимумах (стратегия не успела "отсидеться" перед пиком).
# * Бай-энд-холд спота дал бы чуть больше (+62.08%) — разница из-за ролла.
# * В рублях результат СИЛЬНО зависит от курса USD/RUB (в 2024-2026 рубль
#   укрепился 90.7 -> ~86.7, что съедает часть долларовой прибыли — см.
#   расчёт с конвертацией в AGENTS.md: +45.7% в рублях против +55% "купи-держи").
#
# ============================================================================
# ИТОГ (долларовая доходность, без комиссий и проскальзывания):
#   Стратегия MLRCI на ES (A, с нач. 2024) : +60.47%
#   Стратегия MLRCI на ES (B, BUY 20.02.2024): +54.08%
#   Бай-энд-холд ES=F                         : +60.63%
#   Бай-энд-холд спот S&P 500                : +62.08%
#   Ролл/финансинг-дрэг ES vs спот           : -0.89% за период (~-0.34%/год)
#
# Инструменты: CME E-mini ES=F (история 2023+), SP500F (MOEX, только с авг 2026,
# история для бэктеста с 2024 отсутствует). СПБ Биржа из окружения недоступна.
# ============================================================================

# ----------------------------------------------------------------------------
# 7. ГИПОТЕТИЧЕСКАЯ ДОХОДНОСТЬ: ЕСЛИ БЫ SP500F (MOEX) БЫЛ ДОСТУПЕН С 2024
# ----------------------------------------------------------------------------
# SP500F — фьючерс MOEX на S&P 500 (биржевой контракт, появился в авг 2026).
# Свойства контракта (MOEX ISS, 31.08.2026):
#   * Цена пункта ~ 771  =  S&P 500 / 10 (в 10 раз меньше индекса).
#   * Лот 1, шаг 0.1 пункта, STEPPRICE ~ 8.56 ₽/шаг.
#   * Расчёты в РУБЛЯХ (LAST_RUB = 66 007 ₽ при ~771 пунктах: 771 x 85.6 ≈ 66 007).
#   * Текущий объём ~ 2.57 млн ₽/день — низкая ликвидность (только запустился).
#   * Контракт "постоянный" (LASTTRADEDATE=2100): отслеживает индекс/10, поэтому
#     НЕ имеет ролл-дрэга как ES (нет перехода между квартальными контрактами).
#
# Если бы SP500F торговался с 01.2024, его цена = S&P 500 / 10 на ту же дату,
# поэтому ДОЛЛАРОВАЯ доходность (в пунктах) была бы РАВНА доходности спота SPX:
#
#   Стратегия MLRCI на SP500F (A, лонг с 02.01.2024 -> SELL 07.08.2026):
#      цена = SPX/10: (7709.96/10)/(4769.83/10) - 1 = +61.64%
#      (совпадает со спотом SPX за те же даты: 4769.83 -> 7709.96)
#   Стратегия MLRCI на SP500F (B, BUY 20.02.2024: 5005.57/10 -> 7709.96/10):
#      = +54.04%
#   Бай-энд-холд SP500F 02.01.2024 -> 28.08.2026:
#      = +62.08%  (в точности = спот SPX, БЕЗ ролл-дрэга)
#
# Сравнение с ES=F (у которого ролл съедает ~0.9%):
#   SP500F (гипотетически, USD): +62.08% бай-энд-холд (как спот, без дрэга)
#   ES=F     (реально, USD):     +60.63% бай-энд-холд (ролл-дрэг -0.89%)
#   Разница = ровно ролл-дрэг ES, которого у SP500F нет.
#
# ВАЖНЫЕ ОГОВОРКИ:
#   1. SP500F на реальной MOEX расчётно-поставочный В РУБЛЯХ: фактическая
#      доходность инвестора = долларовая доходность x курс USD/RUB.
#      При курсе 90.7 (01.2024) -> ~85.6-87 (08.2026) рубль укрепился, поэтому
#      рублёвая доходность была бы НИЖЕ долларовой (см. AGENTS.md: +45.7%).
#   2. Доходность без учёта комиссий MOEX, спреда и ликвидности SP500F.
#   3. Пункт/10 и лот 1 делают SP500F удобным малым лотом (≈66 000 ₽ за контракт
#      на авг 2026), но низкая ликвидность (тыс. ₽ в день) сейчас — риск.
#
# ИТОГОВЫЙ ВЫВОД ПО SP500F:
#   Если бы SP500F существовал с 2024, стратегия MLRCI дала бы в долларах
#   +61.64% (вариант A, вход с начала 2024) / +54.04% (вариант B, BUY 20.02.2024),
#   а бай-энд-холд +62.08% — то есть ТАКУЮ ЖЕ доходность, как спот S&P 500,
#   без потери на ролле ES. Это лучше, чем ES=F (+60.63%), на величину
#   ролл-дрэга (~0.9%), и идентично споту. В рублях результат был бы ниже
#   из-за укрепления рубля (90.7 -> ~85.6).
# ============================================================================
