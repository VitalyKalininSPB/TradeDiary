TradeDiary — инструкция по UI
(симуляция портфеля + технический анализ, Simple Mode)

Документ отвечает на вопрос «куда нажимать, чтобы собрать портфель и понять,
как программа в этом помогает и какие у неё ограничения». Пропустите Quant и
Qual Assessment только вскользь (они уже отлажены) — здесь важно, КАК пройти
этот шаг в UI, а не разбирать сами оценки.

Содержание
  1. Запуск
  2. Главное окно — карта
  3. Simple Mode (тумблер)
  4. Баланс и equity
  5. Как найти компанию и добавить её в Watchlist
  6. Обязательный шаг перед сделкой (Quant + Qual gate)
  7. Watchlist: колонки, кнопки, таб Events
  8. Technical timing (колонка Tech / диалог / контекст в сделке)
  9. DealDialog: открытие сделки и Risk plan
  10. Ограничения и предупреждения (сводка)
  11. Управление портфелем: редактирование, закрытие, удаление, история
  12. Контроль рисков: корреляция и Portfolio context
  13. Recalc SL/TP
  14. Макро-инструменты и «градусник»
  15. Катализаторы и напоминания (коза)
  16. Графики
  17. Где что хранится
  18. Быстрый чеклист «собрать портфель»

===========================================================
1. ЗАПУСК
===========================================================
  source .qtcreator/Python_3_12_3venv/bin/activate
  bash run.sh            # = python main.py

Откроется главное окно на весь экран (тёмная тема). Кнопки ниже — по факту,
как они подписаны в интерфейсе.

===========================================================
2. ГЛАВНОЕ ОКНО — КАРТА
===========================================================
Сверху вниз:

[Верхняя строка]
  Equity:   [поле]  $      — капитал (cash + стоимость открытых позиций).
                            Значение читается, но редактируется автоматически
                            из Balance и позиций.
  Balance:  [поле]  $      — свободные деньги (cash). ЭТО поле редактируется:
                            вводишь число → Enter → становится базой баланса.
  ────────────────────────
  [Long] [Short]           — открыть форму сделки (покупка / шорт).
  [Recalc SL/TP]           — автопересчёт стопов по портфелю (в Simple Mode
                             отключён — см. раздел 13).
  [Deal History]           — окно истории сделок.
  [Update]                 — кнопка-заглушка: автообновление котировок
                             отключено, покажет сообщение.
  ────────────────────────
  [⚡ Simple Mode]          — глобальный тумблер простой карточки тикера
                             (запоминается между запусками). Правый верх.

[Таблица сделок] (середина, растягивается)
  Колонки: Ticker, Price, Amount, Open At, InitPrice, TP, SL, System,
           Result, Close At, What's next, Notes, [Chart], [Candles], [Delete].
  Цвет строки: зелёный — цена выше цены входа, красный — ниже.
  Клик по строке — редактирование сделки (EditDealDialog).
  [Chart]    — график скользящих средних (MAChartDialog).
  [Candles]  — свечной график.
  [Delete]   — удалить сделку (с подтверждением).

[Нижняя строка 1 — макро и корреляция]
  Макро:  [градусник][иконка быка/медведя]
          [Макро] [Индексы] [Commodities] [Statements] [Today macro]
  Корр:   [шкала корреляции][комментарий] [Correlation Matrix]

[Нижняя строка 2]
  [Clear DB] [Quant. Assessment] [Qual. Assessment] [Watchlist]

Под строками (только в Simple Mode) — панель «Portfolio context»:
  Open ideas: N (обычный диапазон 5–8) · Normal/Info/Review
  Largest idea: TICKER — $X (Y% of equity)
  Concentration: Normal/Elevated/High + пояснение
  Market context: bull/bear/neutral (+late-cycle)

Кликабельная «коза» (Clippy) в углу экрана: показывает советы и уведомления.
Клик по ней — случайная шутка.

===========================================================
3. SIMPLE MODE (ТУМБЛЕР)
===========================================================
Кнопка «⚡ Simple Mode» в правом верхнем углу. Включена по умолчанию.
Что меняется:
  - Карточка тикера везде компактная (Simple Mode): вердикт, 3 факта,
    катализатор, earnings, действие. Выключено — полный анализ с графиками
    P/E и EPS growth.
  - Появляется панель «Portfolio context» внизу главного окна.
  - Кнопка «Recalc SL/TP» блокируется (стопы задаются вручную).
Для симуляции портфеля держите Simple Mode включённым.

===========================================================
4. БАЛАНС И EQUITY
===========================================================
  - Впишите стартовые деньги в поле Balance (USD) → Enter.
  - Equity считается сам: Balance + стоимость открытых позиций (USD,
    с конвертацией RUB→USD по актуальному курсу).
  - При покупке Balance уменьшается на стоимость позиции (для RUB — в USD).
  - При закрытии сделки выручка возвращается в Balance.
  - Идеи: 5–8 открытых позиций — «нормальный диапазон» (подсказка в
    Portfolio context; меньше 5 — Info, больше 8 — Review).

===========================================================
5. КАК НАЙТИ КОМПАНИЮ И ДОБАВИТЬ ЕЁ В WATCHLIST
===========================================================
Путь А — по секторам (рекомендуется для симуляции):
  1. Нажмите [Quant. Assessment].
  2. В окне «Sector Quantitative Assessment» — таблица секторов
     (Rank, Sector, Signal, Score, Next step). Одиночный клик — детали
     сектора внизу; ДВОЙНОЙ клик по сектору → окно «Companies — Сектор».
  3. В окне Companies две вкладки:
       Long candidates   — сильные компании (скорированные сверху вниз);
       Short candidates  — худшие (для идеи шорт).
     Клик по компании → справа появляется карточка «Рекомендация» (в Simple
     Mode — вердикт + 3 факта) и текст «Почему попала в shortlist».
     У каждой строки кнопка [Сравнение с сектором] → полный диалог сравнения.
  4. Кнопка [Add to watchlist] (внизу окна) → откроется форма
     «Watchlist entry»:
        Ticker (проставлен), Status, Reason, Note → OK.
     Запись сохраняется в Watchlist ВМЕСТЕ с Quant-скоро этой компании.
  5. Кнопка [Qualitative Assessment] → откроется Qual-оценка с уже
     подставленным тикером (см. раздел 6).

Путь Б — по произвольному тикеру:
  1. [Quant. Assessment] → вверху поле «Ticker: ...» + кнопка [Анализ].
  2. Введите тикер (например, AMD) → [Анализ]. Фоновый поток загрузит метрики
     → откроется диалог «Сравнение с сектором — AMD» (Simple-карточка сверху).
  3. В этом диалоге кнопка [Add to Watchlist] (идемпотентно: если тикер уже
     в watchlist — кнопка станет «In Watchlist» и отключится).

Что видно на Simple-карточке (вердикты):
  Candidate / Watchlist / Skip / Нет данных — цветные.
  Ниже: факты (прогноз EPS vs сектор, оценка forward P/E, качество данных),
  строка катализатора, даты отчётов и «Действие».
  Кнопка [Details ▾] раскрывает полный анализ (вкладки P/E, EPS growth,
  Подтверждение, Earnings, Статус данных).

Статусы записи Watchlist (колонка Status): Research / Watching / Rejected /
Owned. Цвета: Research — синий, Watching — янтарный, Rejected — красный,
Owned — зелёный.

===========================================================
6. ОБЯЗАТЕЛЬНЫЙ ШАГ ПЕРЕД СДЕЛКОЙ (QUANT + QUAL GATE)
===========================================================
Программа НЕ даст сохранить сделку, пока у тикера нет обоих Assessment:
  - Quant ✓ — ставится автоматически при «Add to watchlist» из Quant/
    Companies (в карточке есть скор);
  - Qual ✓ — ставится по итогам Qualitative Assessment.

Как получить Qual (кратко):
  - В окне Companies нажмите [Qualitative Assessment] (тикер подставится),
    ИЛИ в главном окне [Qual. Assessment] и введите тикер.
  - Пройдите этапы (оценки звёздами + заметки), в конце — «Quality result»
    (тезис) и кнопка [Add to Watchlist] — она сохранит запись ВМЕСТЕ с Qual.
  - Проверка: в Watchlist колонки «Quant ✓» и «Qual ✓» — 💡 (жёлтая лампочка).
  Если чего-то не хватает — при попытке сохранить сделку DealDialog покажет
  «Не пройден Assessment: Quant и/или Qual. Сделка запрещена…» и козу-подсказку.

===========================================================
7. WATCHLIST: КОЛОНКИ, КНОПКИ, ТАБ EVENTS
===========================================================
Открытие: [Watchlist] в главном окне.

Таб «Watchlist» — таблица:
  Ticker | Status | Date | Reason | Quant | Quant ✓ | Qual | Qual ✓
  | Catalyst | Tech | Note

  - Quant / Qual: значение скора (например «+1.23», «4.10/5»).
  - Quant ✓ / Qual ✓: 💡 = assessment пройден; «—» = нет.
    Двойной клик по Qual-колонке — просмотр полного Qual-отчёта.
  - Catalyst: «кол-во · ближайшая дата · макс 0-5». Красный = событие наступило/
    просрочено. Двойной клик по колонке — менеджер катализаторов тикера.
  - Tech: технический статус (READY TO CONSIDER ENTRY / WAIT / REASSESS /
    Нет данных), цветной. Считается автоматически при открытии окна.
    «…» = ещё считается в фоне. Двойной клик по колонке — диалог Technical
    timing (раздел 8).

Кнопки: [Add] [Edit] [Remove] [Chart] [Catalyst] [Technical]
        [Test notify (15s)] [Close]
  - Add / Edit / Remove — управление записями (форма «Watchlist entry»).
  - Chart — график MA выбранного тикера.
  - Catalyst — менеджер катализаторов выбранного тикера.
  - Technical — диалог технического статуса (раздел 8).
  - Test notify — тест уведомления козы через 15 секунд.

Таб «Events» — ВСЕ катализаторы по всем тикерам: Ticker, Дата, Балл, Напр,
Описание, Ожидание. Кнопки Add/Edit/Delete/Refresh. Просроченные даты — красным.

Добавить катализатор: [Add] → форма CatalystEventDialog:
  календарь (дата), звёзды 0–5 (отчётливость события, НЕ благоприятность),
  направление +/−/±, описание, «ожидание» (какой исход/метрика удивит).

===========================================================
8. TECHNICAL TIMING (КОЛОНКА TECH / ДИАЛОГ / КОНТЕКСТ В СДЕЛКЕ)
===========================================================
Что это: «готов ли тикер рассматривать вход?». Не Buy-сигнал и не поиск
идеального входа. Статус = «нет сильного технического конфликта» со стороной
идеи (по умолчанию для Watchlist — Long).

Статусы (колонка Tech):
  READY TO CONSIDER ENTRY  — зелёный: тренд и momentum не конфликтуют;
  WAIT                     — жёлтый: один конфликт (частично против);
  REASSESS                 — красный: 2–3 конфликта — проверить,
                              не изменился ли фундаментальный тезис;
  Нет данных               — серый: меньше ~220 торговых дней истории.
Конфликты для Long: цена ниже SMA 200 / death cross (SMA 50 < SMA 200) /
MACD медвежий. Для Short — зеркально (но Watchlist считает Long).
RSI/перегрев НЕ блокирует: при READY + перегретом RSI появляется мягкое
предупреждение (жёлтая строка), статус остаётся READY.

Диалог (двойной клик по колонке Tech или кнопка [Technical]):
  Status (цветной), Trend (Price vs SMA 200, SMA 50 vs SMA 200), Momentum
  (RSI(14), MACD), Reason (русский текст), жёлтое Warning, дата данных.
  Кнопки:
    [Open trade plan] — открыть DealDialog с этим тикером (Long), там уже
                        будет блок «Technical context» и, при перегреве,
                        подсказка козы;
    [View chart]      — график MA;
    [Keep watching]   — просто закрыть.

Контекст в DealDialog (блок «Technical context»):
  Status, Price vs SMA 200, SMA 50/200, RSI(14), MACD, Stop reference
  (для Long — ближайшая поддержка, для Short — сопротивление) + кнопка Chart.
  Индикаторы НЕ подставляют стоп автоматически — это контекст, стоп выбираете вы.
  Расчёт в DealDialog не запускается: берётся последний результат из БД
  Watchlist (данные обновляются при открытии Watchlist).

===========================================================
9. DEALDIALOG: ОТКРЫТИЕ СДЕЛКИ И RISK PLAN
===========================================================
Как открыть:
  - [Long] или [Short] в главном окне, или
  - Watchlist → [Technical] → [Open trade plan] (тикер уже подставлен).

Поля формы:
  Ticker      — ввод; после паузы автоматически подтянутся логотип и текущая
                цена (для MOEX — рубли, для мира — доллары). Вместе с этим
                обновляется блок «Technical context» (если есть кэш).
  Stock Price — цена входа (подставляется, можно править).
  Amount      — количество.
  Desired amount (USD) — сколько долларов хотите потратить → при выходе из
                поля пересчитается количество (floor, целое число акций).
  Stop Loss / Take Profit — задаёте сами (подсказки меток меняются по
                направлению: Long «Stop Loss (<=)», Short «Stop Loss (>=)»).
  Trade System — выпадающий список (Average MA / MACD).

Блок «Risk plan» (считается сразу при вводе):
  Risk per share      = |entry − stop|;
  Position value      = entry × amount;
  Risk at stop        = риск × amount; при положительном equity также
                        «(X.XX% of equity)».

Блок «Technical context» — см. раздел 8.

При попытке сохранить (OK):
  - Блокеры (ошибки — сделку сохранить нельзя): не пройден Quant/Qual gate;
    нет стопа; стоп не той стороны (Long: stop ≥ entry; Short: stop ≤ entry);
    entry ≤ 0; amount ≤ 0. Текст ошибки — в окне формы (у поля стопа).
  - Warnings (не блокируют, спрашивают подтверждение Yes/No):
      · позиция больше $10 000 на одну идею;
      · риск на стопе больше 1% equity (ваш лимит на сделку);
      · риск больше 2% equity (сильное предупреждение).
    Плюс отдельная проверка «риск больше 2% баланса» — тоже с подтверждением.
  При Yes — сделка сохраняется: строка появляется в таблице, Balance
  уменьшается (для RUB — с конвертацией), пересчитываются корреляция и
  Portfolio context.

===========================================================
10. ОГРАНИЧЕНИЯ И ПРЕДУПРЕЖДЕНИЯ (СВОДКА)
===========================================================
Блокируют открытие сделки (DealDialog):
  - Нет Quant или Qual в Watchlist (gate).
  - Нет stop-loss.
  - Stop-loss не той стороны (Long: должен быть ниже entry; Short: выше).
  - Entry ≤ 0, количество ≤ 0.

Предупреждают, но НЕ блокируют (подтверждение Yes/No):
  - Позиция > $10 000 (лимит на одну идею).
  - Риск на стопе > 1% equity.
  - Риск > 2% equity (сильное предупреждение) и отдельно риск > 2% баланса.
  - (в EditDealDialog) «Risk is exceeded 2% of balance» — то же подтверждение.

Информационные подсказки (не блокируют):
  - RSI перегрет/перепродан при READY — «не гнаться за импульсом».
  - Portfolio context: <5 идей — Info, >8 идей — Review, концентрация
    Elevated/High.
  - Корреляция: комментарий под шкалой + тултип.

Прочее:
  - [Update] (котировки) — отключена, покажет сообщение. Цены подтягиваются
    автоматически при добавлении тикера.
  - [Recalc SL/TP] в Simple Mode — отключён (стопы задаются вручную).
  - Фьючерсы: только префиксы NASD-/GOLD- обрабатываются специально
    (риск на «пункт» через pointPrice); остальное — как акции.
  - Рынки: MOEX (RUB) и зарубежные (USD). Других валют нет.

===========================================================
11. УПРАВЛЕНИЕ ПОРТФЕЛЕМ
===========================================================
Редактирование: клик по строке таблицы → EditDealDialog:
  - открытая сделка: правьте цену, стоп, тейк, систему, What's next, Notes;
  - кнопка [Close Deal] — закрыть сделку (проставит дату закрытия сейчас);
    после OK выручка вернётся в Balance, сделка уйдёт из таблицы в историю.
Закрытая сделка (строка с датой закрытия): правка только вводных (What's next,
Notes); цена и система заблокированы.

Удаление: [Delete] в строке → подтверждение → позиция исчезает, Balance и
корреляция пересчитываются.

История: [Deal History] в главном окне. Пока реальной истории закрытий нет —
диалог генерирует демо-историю из открытых позиций для наглядного вывода.

===========================================================
12. КОНТРОЛЬ РИСКОВ: КОРРЕЛЯЦИЯ И PORTFOLIO CONTEXT
===========================================================
Корреляция (шкала «Корр:»): средневзвешенная (по USD-стоимости) попарная
корреляция дневных доходностей открытых позиций за ~90 дней.
Зоны (цвет шкалы):
  < 0.20 — «Консервативно» (активы почти не связаны);
  0.20–0.35 — «Нейтрально»;
  0.35–0.55 — «Хорошо» (золотая зона, зелёная);
  0.55–0.70 — «Повышенный» (активы схожи — проверьте дубли);
  > 0.70   — «Риск» (всё движется синхронно — высокая концентрация).
Тултип на шкале — объяснение. [Correlation Matrix] — тепловая карта (нужно
минимум 2 открытые позиции).

Portfolio context (Simple Mode, внизу главного окна):
  - Open ideas: N · Normal/Info/Review (норма 5–8);
  - Largest idea: тикер, $, % equity;
  - Concentration: Normal/Elevated/High — сопоставлена с зонами корреляции
    (≤0.55 / до 0.70 / >0.70) + одна строка пояснения;
  - Market context: bull/bear/neutral (+ late-cycle, если сигнал активен).
Это только информация: ничего не блокирует и не меняет.

===========================================================
13. RECALC SL/TP
===========================================================
Кнопка [Recalc SL/TP]:
  - В Simple Mode → сообщение «В Simple Mode stop-loss и take-profit задаются
    вручную — автоматический пересчёт отключён.» (и ничего не делает).
  - В полном режиме → агрегирует все открытые сделки по тикерам и считает
    SL/TP из единого риск-бюджета, зависящего от корреляции портфеля
    (риск в % от equity → стоп = цена ∓ риск/кол-во; TP = RR:1). Записывает
    одинаковые SL/TP во все сделки тикера. Пропускает фьючерсы и сделки без
    данных (отчитается «Skipped: …»).

===========================================================
14. МАКРО-ИНСТРУМЕНТЫ И «ГРАДУСНИК»
===========================================================
«Градусник» (шкала «Макро:»): риск-on/off температура −10..+10 из FRED.
  Теплее/зеленее слева (низкое значение) — ближе к риску; краснее справа.
  Тултип — пояснение. Рядом иконка быка/медведя — режим рынка по NASDAQ100
  (цена vs 200-SMA).
  Считается в фоне при старте (из кэша мгновенно, потом пересчёт).

Кнопки:
  [Макро]      — диалог макро-индикаторов (вкладки FRED-рядов; на табе
                 Real Interest Rate (Ex-Ante) по умолчанию включены «Точки
                 перегиба»: пик ставки → BUY S&P (зелёный ▲), впадина →
                 SELL S&P (красный ▼); внизу таба GDP — фаза цикла и метка
                 позднего цикла).
  [Индексы]    — NAS100 / SP500 / DAX (режим bull/bear, точки перегиба,
                 подсказки про опережение NASDAQ).
  [Commodities]— товарные ряды.
  [Statements] — лента заявлений FOMC (непрочитанные — «коза» напомнит).
  [Today macro]— встроенный браузер с сегодняшними событиями S&P/NASDAQ.

15. КАТАЛИЗАТОРЫ И НАПОМИНАНИЯ (КОЗА)
===========================================================
  - Катализатор — событие, способное двинуть акцию: дата (напоминание за
    сутки), балл 0–5 (отчётливость), направление +/−/±, описание, ожидание.
  - Добавить/править: Watchlist → двойной клик по колонке Catalyst (или
    [Catalyst]) → CatalystDialog; общий список — таб Events.
  - Напоминания: при старте и далее раз в час. Приближающиеся/просроченные
    события показываются козой с красным крестиком подтверждения — пока не
    подтвердите, другие уведомления подавлены.
  - Коза в главном окне также сообщает: непрочитанные FOMC, поздний цикл,
    Quant-алерты (смена сигналов секторов/компаний).

16. ГРАФИКИ
===========================================================
  - В таблице сделок: [Chart] — MA-график (SMA 20/50, золотые/смертельные
    кресты, анализ крестов), [Candles] — свечи по OHLC.
  - Из Watchlist: [Chart] — тот же MA-график; в Technical-диалоге [View chart].
  - В DealDialog (блок Technical context): [Chart] — MA-график текущего тикера.
  - [Correlation Matrix] — тепловая карта корреляций открытых позиций.
  - [Макро]/[Индексы]/[Commodities] — графики макро-рядов с точками перегиба.
Все диалоги немодальные — можно держать несколько открытыми.

18. БЫСТРЫЙ ЧЕКЛИСТ «СОБРАТЬ ПОРТФЕЛЬ»
===========================================================
  1. [⚡ Simple Mode] — включить (панель Portfolio context появится).
  2. Вписать стартовый Balance (USD) → Enter.
  3. [Quant. Assessment] → двойной клик по сектору → окно Companies.
  4. Кликнуть компанию (Long candidates) → [Add to watchlist] (даст Quant).
  5. [Qualitative Assessment] (тикер подставится) → пройти этапы →
     в конце [Add to Watchlist] (даст Qual).
     → Проверить в Watchlist, что Quant ✓ и Qual ✓ = 💡.
  6. [Watchlist] → следить за колонкой Tech:
       READY      → можно рассматривать вход;
       WAIT       → подождать подтверждения;
       REASSESS   → проверить тезис, не входить сразу;
       Нет данных → недостаточно истории.
  7. [Technical] → [Open trade plan] → DealDialog.
     Убедиться в блоке «Technical context» (статус, тренд, RSI, MACD,
     Stop reference).
  8. В DealDialog: проверить цену, ввести Stop Loss (по правильной стороне),
     количество (или Desired amount USD), посмотреть Risk at stop
     (цель ≤ 1% equity; больше — будет подтверждение).
     OK → позиция в таблице.
  9. Повторить шаги 3–8 до 5–8 идей.
  10. Контроль: Portfolio context (идеи/концентрация), шкала корреляции
      (золотая зона 0.35–0.55), [Correlation Matrix], коза (катализаторы,
      FOMC, поздний цикл).
  11. Управление: клик по строке — правка/закрытие; [Deal History] — история;
      [Delete] — удалить позицию.

Примечание: тех. статусы и цены требуют сети (FRED, MOEX, Yahoo). Без сети
программа работает из кэша (мгновенно), но свежие статусы не обновятся.
